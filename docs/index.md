## 이 사이트 쓰는 법

실습 파일(`.py`)에 주석으로 아래 기호를 달면 노트가 자동으로 만들어집니다.

| 기호 | 뜻 |
|---|---|
| `#==` | 섹션 제목 |
| `#>` | 설명 |
| `#!` | 배운 점 · 막혔던 부분 → 노란 박스 |
| `#?` | 나중에 볼 것 → 하단 체크박스 |
| `#@@@` | 따로 팔 큰 주제 → GitHub 이슈 |
| `#(1)>` | 코드 줄 강조 + 접이식 설명 (`#(1:5)>` 는 여러 줄 강조) |
| `# --8<-- [start]` / `[end]` | 노트에 넣을 코드 구간 표시 |

노트에 넣을 코드는 `# --8<-- [start]` 와 `[end]` 로 감싸야 나옵니다.
